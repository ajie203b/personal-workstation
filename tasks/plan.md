# Muse 体验反馈核查与修复

按当前源码和隔离浏览器中的实际行为逐项核对，不直接照搬体验结论。

1. 共用弹窗补齐关闭入口、添加任务提供取消、危险确认使用统一红色按钮。
2. 日期展示集中到日期工具：列表中文月日、详情时间到分钟；存储及日期输入保留 ISO 日期。
3. 强调色贯通专注主控件，状态色保留给完成/错误；核对深浅色文本、窄侧栏和导航命名。
4. 精简文档库重复卡片，补齐热力图星期，减少四象限及周末的颜色歧义。
5. 独立复现并修复编辑器的选区、高亮与批注操作；记录未复现项和已下线的 AI 模块。

验证：日期/批注回归测试、完整 Vitest 测试、生产构建、桌面和手机浏览器的实际交互与截图。所有验证使用隔离浏览器数据，不触碰用户数据。
