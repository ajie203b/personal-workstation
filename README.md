# Kairos

Kairos（个人工作站）：任务清单 × 文档工作站 × 本地工具合集。**本地优先、数据不出本机（不上传任务或文档内容）、单人不设账号**。

> v3.4.4 · 在线版：<https://ajie203b.github.io/personal-workstation/>
> 三种形态：**安卓 App**（数据存本机，无需服务器）、**Windows 桌面版**（Tauri）与 **网页版 PWA**。

## 获取与安装

- **在线版（推荐，无需安装）**：<https://ajie203b.github.io/personal-workstation/> 打开即用。数据存在各自浏览器的 IndexedDB，GitHub 不存储任何用户数据。
- **安卓 App**：从 [Releases](https://github.com/ajie203b/personal-workstation/releases/latest) 下载 `personal-workstation-v<最新版本>.apk` → 传到手机 → 点击安装（允许「未知来源」）→ 桌面出现「Kairos」图标，全屏独立运行。已装过旧版的可直接覆盖安装，数据不丢；App 启动时会自动检查新版本（每天最多一次，可在「设置 → 关于」关闭），也可以手动「检查更新」，一键下载并拉起系统安装器。
- **Windows 桌面版**：从 [Releases](https://github.com/ajie203b/personal-workstation/releases/latest) 下载 `Kairos_<最新版本>_x64-setup.exe` → 双击安装（当前用户，无需管理员）。WebDAV 同步走原生请求，不受浏览器跨域限制；数据保存在本机。已装旧版可直接覆盖升级；配置好更新签名后，桌面版启动时会自动检查并一键更新（一次性配置见 [docs/构建与发版.md](docs/构建与发版.md#应用内自动更新一次性配置)）。
- **桌面 / 平板 PWA**：浏览器打开在线版 →「安装应用」。同一套代码也是标准 PWA，可部署到任意 HTTPS 静态托管。

> ⚠️ 旧地址 <https://ajie203b.github.io/personal-workstation-site/> 已随站点仓库停用。IndexedDB 按域名隔离，**旧版 PWA 里的数据不会自动搬过来**：请先在旧版「设置 → 数据 → 导出备份」，再到新版导入。

## 功能

### 任务清单

- **四清单时间语义**（Things 3 式）：今日 / 近期 / 随时 / 将来，完成自动入「日志」归档
- **四档优先级**：任务列表直接显示「P0 紧急 / P1 重要 / P2 普通」文字和辅助色点，不只靠颜色区分；P3 保持低干扰。
- **自然语言录入**：`明天14:00 交报告 P1 #工作` 自动解析日期、时间、优先级、标签、重复，并回填时间字段；手动修改或清空后保留用户选择。还能认出次数（`每天喝水8次`）、多个打卡时间（`每天8点、21点`）、预计用时（`读30分钟书`）、只写时段（`明天上午 交材料` → 09:00）与「紧急 / 务必 / 有空」这类优先级线索，猜出来的会在预览里标注。
- **打卡与重复任务**：描述里写「每天」「每周」自动识别；打卡任务可自定义**时间点（可多个）与次数**（如每天 8 次），每点一次记一次、打满才归档；没有设置的开始或截止时间保持未设置，不补创建时刻。
- **桌面 / 负一屏小组件**：今天没做完的任务与打卡进度（2/8）直接显示在桌面或小米负一屏，点整卡回今日页、点单条直达那条任务
- **同数据多视图**：列表 / 看板（跨列拖拽改清单，列内补位有 FLIP 动画）
- **任务详情**：标题、笔记、清单、优先级、截止时间、标签、子任务，外加进行中 / 置顶 / 开始专注 / 删除四个动作。点卡片任意位置以居中弹窗打开，完成只由左侧勾选框触发，误勾可在 toast 里撤销；卡片右侧不再挂「···」菜单，操作统一收进详情
- **安卓桌面快捷方式**：长按桌面图标直接「快速添加」或「今日」，冷启动也落在对应位置
- **两段式时间**：可只选截止时间，也可以分别设开始与截止；任务详情里一键「截止顺延一天」（已有开始时间时一起顺延）。时间按设备本地时区保存与展示。
- **未来任务按开始时间算**：开始时间还没到的任务标「未来任务」（列表里直接显示「明天 08:00 开始」），勾选框暂不可用；开始时间一到就能直接完成，哪怕截止日还在后天。只有没设开始时间的任务才按截止日判断

### 今日与专注

- **今日页**：任务 + 当日进度 KPI + 最近阅读，日期行右侧加号即可添加；底部「随时」分组把没有截止日的任务也带出来，不用切到任务清单
- **番茄钟**：按墙上时钟计时，剩余时间由 `endsAt` 推算并存本机，刷新、关页面、切后台被节流都不漂移；15 / 25 / 45 / 60 分钟四档可选，选择记忆在本机，专注会话按实际时长入库。任务详情点「开始专注」会跳到今日页并弹出选时小框，选好立即开跑（关掉小框则只绑定任务、不启动）
- **提醒与专注通知**：任务提醒点开直达对应任务详情；番茄钟一开始就按 `endsAt` 排一条系统本地通知，锁屏 / 切后台也能收到，暂停、重置或到点会撤掉
- **每日回顾**：今日页底部一张卡——今天完成了什么、还差几件、本周累计多少；没做完的一键挪到明天（清单进「近期」，截止日改明天）

### 文档工作站

- **导入**：PDF / Markdown / TXT / EPUB / Word（DOCX）/ PowerPoint（PPTX），按内容指纹（SHA-256）去重，文件本体存 IndexedDB；文章离线与 OCR 的结果也能直接进文档库
- **Word 格式与公式**：保留 DOCX 原生公式、文字颜色、加粗、底纹和文档样式，按阅读区宽度连续排版；字号可继续调整。旧式 OLE/MathType 对象、复杂浮动绘图和 Word 的精确分页仍受浏览器能力限制。
- **Word 阅读排版**：内置 STIX Two 数学及西文字库，手机离线可用；独立公式居中并保留右侧编号，复合上下标对齐，长公式在正文内部横向滚动。正文段距、标题和表格留白统一优化，作者指定的颜色、加粗和底纹继续保留。字体来源和授权见 `public/fonts/stix/OFL.txt`。
- **Markdown 阅读兼容**：支持 `$…$` / `$$…$$` 数学公式、安全 HTML 加粗与颜色/底纹，并容错恢复复制时被空行拆散的管道表格；不改写原始文件或代码块。Markdown/TXT 导入支持 UTF-8、GBK/GB18030 与 UTF-16。
- **三栏工作区**：左侧目录 + 高亮 + 书签 · 中央阅读画布 · 右侧批注 + 反链（手机为抽屉）；两侧栏可拖拽调宽、双击复位或一键折叠，正文随栏宽重排并保持阅读锚点
- **位置记忆**（Readwise Reader 模式）：瞬时滚动位置与深度阅读进度分开记录，快速翻页不污染进度；关掉重开自动回到上次阅读位置并提示
- **批注三件套**：划词四色高亮（黄 / 绿 / 蓝 / 红）+ 侧栏评论 + 一键转任务（自动携带文档深链与摘录）；PDF 高亮以归一化矩形锚定，Markdown 与流式文档按块/章节保存精确文本选区，支持跨段、跨章节和反向选择，旧批注兼容回放。
- **区域截图批注**：截图模式拖拽框选页面区域，自动裁剪生成本地缩略图，可评论、转任务、定位闪烁
- **多标签阅读**：同时打开多篇文档，标签栏切换 / 关闭（最多 8 个，自动记忆）
- **Markdown 写作**：TipTap 编辑器，工具栏含标题 / 粗斜体 / 列表 / 引用 / 代码块，自动序列化保存；写完再点进去能接着写
- **目录导航**：PDF 大纲（书签）解析跳页；Markdown 按标题解析目录；支持用户书签，书签带该处第一句摘录
- **双向关联**：「哪些任务引用了本文档」可逆查询并跳转；任务卡上的文档引用可点直达阅读位置（含页码 / 块锚点 / 批注闪烁）
- **Markdown 插图**：编辑器工具栏选图、⌘V 粘贴或直接把图片拖进正文；大图自动等比缩到最长边 1600px 再内嵌，导出与同步都自带，不依赖图床
- **文档内缩放**：双指只在阅读画布上生效——PDF 放大页宽（50%–300%，右下角一键重置），Markdown / Word / EPUB 放大字号（14–32px）并重排；整页缩放已关闭，不会再连侧栏与底栏一起放大
- **正文链接**：外部链接交给系统浏览器打开，`#标题` 锚点在本页跳转，相对路径不会再把应用带回首页
- **文件夹**：把长期任务相关的资料收进一个文件夹——任务详情里创建/关联后可直接打开，文档库顶部按文件夹筛选，文件夹里导入的文档自动归属
- **读完提醒**：阅读进度第一次到 100% 时，如果还有引用本文档的未完成任务，弹窗让你勾选完成，不用再切到任务清单去找
- **高亮复习**：划词高亮从次日起进入复习队列，`/review` 逐张过（忘了 / 困难 / 一般 / 简单），按简化 SM-2 把间隔从 1 天逐步拉到几个月；答案面带你的评论与原文入口，今日页显示到期张数

### 工具矩阵

工具页顶部是 Artificial Analysis 智能指数官方榜单原图，每天自动拉取最新图表；可左右滑动、鼠标拖动、查看完整原图，离线时回退到随应用内置的上一版；下面是七张工具卡：

- **番茄小说**：搜书名或贴链接，把整本小说下载到本地书架，导出 TXT / EPUB，也可导入文档库
- **无水印下载**：粘贴抖音 / B 站分享文案，解析视频或图集并下载到「下载/个人工作站」；抖音走移动端公开接口（常见 720P），B 站未登录上限 720P，平台接口变动时会明确报错
- **二维码**：生成文本 / 网址 / WiFi / 名片 / 邮件 / 短信六类二维码，点型、码眼、渐变与 Logo 可调，导出 PNG（512 / 1024 / 2048）或 SVG，生成后自动模拟扫码自检；扫码支持拍照、相册、粘贴图片与可选实时相机，结果可复制或转任务，生成与扫码历史都能复用
- **PDF 工具箱**：合并、拆分提取、拖动整理页面、图转 PDF、指定页转图、水印页码、多签名、三档压缩与 AES-256 加密/已知密码解密；引擎随包离线可用，处理支持进度和取消。PDF 可下载或入库，ZIP/图片和加密副本提供下载。
- **文章离线**：粘贴网页链接抓正文（微信 / CSDN 有专门适配），图片本地化后存入文档库（同一链接可更新旧文档）或导出 EPUB；登录墙站点可用「粘贴正文」兜底，带格式粘贴会连图片一起解析
- **证件照**：相册 / 拍照选图，自动人脸取景并按双眼扶正、MODNet 抠图换底、按报名规格裁剪并压到指定 KB、6 寸排版导出 PDF / JPG，也能保存自定义规格；首次抠图会下载约 25MB 模型
- **本地 OCR**：相册 / 拍照 / 粘贴截图，本地识别中文，图上点框复制、低置信度标黄，全文可编辑并复制、存为 Markdown 文档或转任务；识别模型首次使用时下载

### 统计、命令面板与快捷键

- **统计页**：近半年热力图、本周 vs 上周、常做领域（按完成任务标签）、专注最多的任务
- **⌘K 命令面板**：全局搜索任务 / 文档 + 快捷动作（新建任务、新建文档、导航、切主题），任意位置呼出，全键盘操作
- **键盘流**：`N` 或 `/` 快速添加、`↑↓ / J K` 选择、`空格 / X` 勾选、`Enter` 开详情、`⌘/Ctrl+Z` 撤销最近一次操作、`?` 看帮助；快捷键提示在 macOS 上显示 ⌘、其他平台显示 Ctrl

### 外观、排版与动效

- **外观三分区**（设置 → 外观，macOS 系统设置的路数）：主题三档（跟随系统 / 浅色 / 深色，跟随系统会实时响应系统切换）、6 种强调色（覆盖 `--primary` 系令牌，深浅色各一套，主按钮、链接、选中态与番茄钟随之换色）、动效总开关（关掉后应用内动画减至最弱，独立于系统的减弱动效）
- **阅读排版四主题**：日间 / 夜间 / 羊皮纸 / 暮色，字号、行距、页宽**按文档记忆**；正文宽度改为连续滑杆（50–100%），文字与插图随宽度重排，PDF 按阅读区宽度自适应；PDF 夜间自动反色且不破坏图像层次。深浅色切换在有 View Transitions 的浏览器里走交叉淡入
- **动效原则**：只用 `transform` / `opacity`，时长取 CSS 令牌；系统开启「减弱动态效果」或关掉应用内动效时，粒子、光环、扩散一类特效直接不出现，而不是加速播完
- **共享元素转场**：列表卡片 → 详情用 View Transitions API 连续生长，而不是各播各的淡入
- **触觉反馈**：安卓壳内走原生 Haptics，网页端回退 `navigator.vibrate`；勾选完成、拖起落下、开关切换、长按确认、底部导航各一档
- **细节手感**：勾选立即提交，完成光环独立播放约 320ms，切页也不会丢失操作；误勾可通过提示里的「撤销」恢复。按钮提供 idle/loading/success/error 四态，列表增删用 FLIP 平滑补位，抽屉支持跟手关闭。弹层保留单一空间转场，字段同步呈现；开关与底栏胶囊轻微回弹，分段控件直接滑向目标。系统减弱动效与应用内开关共同控制 CSS 和 JS 动画。
- **轻盈工作台**：雾白画布、白色内容卡与清晰的辅助文字；导航采用小马线描标记，完整插画保留为应用图标。任务优先级使用单一色点，文档卡的阅读、写作、移动和删除操作集中到菜单，删除前统一确认。看板保持至少 260px 列宽；阅读时全局侧栏自动收窄，手机正文两侧留白 22px，平板按宽度将目录或批注收进抽屉。

### 数据安全

- IndexedDB 本地持久化；设置页可导出 / 导入 JSON 备份（含文档库）、清空数据
- **自动备份**：本机 OPFS 滚动快照，打开应用时距上次超过 24 小时就静默写一份，永远保留最近 3 份，设置 → 数据 里可一键恢复；恢复是**替换**（回到快照那一刻），不是把快照合并进现数据
- **坚果云同步**（设置 → 同步）：默认只填坚果云账号与应用密码，目录自动填好，可打开「自动同步」；其他 WebDAV 收在「高级」里。任务、文档本体、批注、书签在安卓与 Windows 桌面版之间合并；按更新时间取新、删除用墓碑防复活、清空会整份覆盖另一端；口令只存本机，不随同步或备份导出。两端都走原生请求，不受浏览器跨域限制；网页版受浏览器跨域限制，连不上坚果云
- **工具数据**：二维码历史与手写签名存本机，会进 JSON 备份 / 自动快照，但不参与 WebDAV 同步；OCR / 证件照模型存在 Cache Storage，不进备份、同步或导出

## 界面形态

- **桌面 ≥1024px**：完整侧栏（可折叠）
- **平板 / 窄窗口 768–1023px**：图标栏侧栏
- **手机 <768px**：顶栏（状态栏安全区适配）+ 底部标签导航；**左上角应用图标 = 设置入口**

## 数据与隐私

- 所有数据保存在本机（App 沙箱 / 浏览器 IndexedDB），不上传任何服务器
- OCR、证件照、二维码、PDF 与文章正文 / 图片处理都在本机完成，不上传原图、正文或识别结果
- 联网只用于：抓取你主动粘贴的网页 / 视频链接、首次下载 OCR 与抠图模型、检查更新、同步（如果你开启），以及打开榜单官网入口
- **卸载 App 会删除其沙箱内数据**，同签名覆盖升级不影响
- 更新检测只读取 GitHub 上的公开静态清单与 Release 信息，不含任何用户数据
- 模型排名使用随应用提供的官方原图；打开官网入口时会访问 Artificial Analysis，不上传任务或文档数据
- 导出备份 / 自动快照只打包任务、文档、批注这些内容本身：WebDAV 口令、坚果云应用密码这类凭据一律不写进文件，同步也不带

```
src/
├─ app/             # AppShell、侧栏 / 底栏 / 顶栏、路由与转场
├─ modules/
```
