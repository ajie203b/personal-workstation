# 安卓交互优化

范围：文档页入口、任务与工具排序、导航角标、任务时间录入。

- 文档页去掉添加任务的悬浮加号。手机搜索框右侧直接显示写文档、导入的纯图标按钮；三点菜单保留高亮复习、新建文件夹。桌面按钮保留文字。
- 任务列表长按约 320 毫秒起拖，支持拖到指定位置；看板同列也能保存顺序。顺序保存在任务数据中，刷新后保留。隐藏任务保留槽位，跨置顶区域拖动时跟随落点的置顶状态。
- 小工具长按排序，设置持久保存；新增工具追加到末尾。模型智能排名不进入拖动区域，始终在首位。
- 导航改为今日、任务清单、文档工作站、工具、统计。任务角标从 18 缩到 15 像素，右移 2 像素。
- 添加任务的时间区默认收起，识别出时间或重复安排时自动展开，仍可手动收起。自动识别的多个打卡时间直接回填，允许逐个删除；手动修改优先。
- 年、月、日改用自绘日历，支持跳选年月、闰日、快捷日期和清除；添加任务与任务详情统一使用。只选日期时不再额外填入 09:00，未设置时间保持为空。
- 解析支持星期、礼拜、周的数字/汉字/全角和混合写法，多星期与星期区间，中文分钟、刻钟、早晚简称、混搭次数和多个时间点。明确写了日期时不再根据当前时刻把早上的钟点误猜成晚上；否定的重要程度和序号避免误判。

验证：563 项 Vitest 测试、TypeScript 与 Vite 生产构建通过；隔离 Chrome 手机触摸模拟验证长按任务/工具排序、刷新持久化、拖后不误开详情、键盘排序、时间自动展开和日历。文档页在 320、768、1024、1440 像素宽度下无横向溢出，运行期间无 JavaScript 异常。

本地安卓包：`apk/Kairos-Android-UI-20261023.apk`，沿用当前工程版本 3.3.5（versionCode 63）。离线 assembleRelease 成功；解包逐字节确认 69 个 JS/CSS/HTML 文件与本次生产构建一致。

截图与浏览器验证记录存放在本机忽略目录 `testdata-sample.mobile/`。未对 Android 真机执行安装测试。
