# 按钮「手感」特效：视频提取 + 本项目动效方案

来源视频：`别再只说做个好看的按钮了这4个提示词让按钮有手感`（720×1280，69.7s，30fps，带烧录字幕）
提取方式：ffmpeg 每 2s 抽帧 + 关键帧裁切放大读字幕（本机无 ASR，音频轨未转写）。
四栏汇总原帧已存为 `docs/动效参考-四条提示词.jpg`。

---

## 1. 视频讲了什么

结构：片头 0–8s → 01 点赞爆粒子 8–24s → 02 提交按钮三连变 24–38s → 03 果冻开关 38–56s → 04 长按确认 56–66s → 汇总 66–70s。

每个 case 的讲法是固定套路，这部分比特效本身更值得学：

- 左侧手机原型演示效果；
- 右侧 **LIVE READOUT 实时参数面板**：把抽象的「手感」变成可见数值（SCALE 缩放 1.00×、PARTICLES 8 个、WIDTH 500→72px、OFFSET 54px、HOLD 0.10s、PROGRESS 7%），旁边画出缓动曲线并让一个光点沿曲线跑；
- 底部先给红卡「常见写法 · 效果平平」：`做个好看的点赞按钮` → AI 多半只会换颜色；
- 再给绿卡「AI 描述词 · 正确写法 · 复制即用」；
- 右下角一行参数标签：`EASE BACK-OUT · 600MS · 8 DOTS`；
- 顶部可切换「按提示词 · 慢放 0.35×」与「常见写法效果」做 A/B 对比。

## 2. 四条提示词（逐字）

**01 · 点赞爆粒子（LIKE BURST）**
做一个点赞按钮（Like Burst）：点击后爱心先缩小到 0.8 倍再弹到 1.2 倍，最后回到 1 倍，同时由灰色变成红色；爱心周围炸开 8 个彩色小圆点，向外飞散并淡出；右边的点赞数向上滚动 +1。总时长约 600ms，弹跳使用带回弹的曲线。

**02 · 提交按钮三连变（SUBMIT MORPH）**
做一个提交按钮三段变化（Submit Morph）：点击后文字淡出，按钮宽度收缩成圆形，圆形中间出现旋转的加载圆环；1.2 秒后按钮变成绿色并画出对勾；再过 1 秒恢复原状。收缩约 300ms，使用 ease-in-out。

**03 · 果冻开关（JELLY TOGGLE）**
做一个果冻开关（Jelly Toggle）：点击后圆点滑向另一端，滑动途中先横向拉长成胶囊形，到达终点回弹恢复圆形；底色从灰色渐变为绿色。时长约 350ms，使用带回弹的弹簧曲线。

**04 · 长按确认（HOLD TO CONFIRM）**
做一个长按确认按钮（Hold to Confirm）：圆形删除按钮，按住时外圈进度环顺时针走满，用时 1.5 秒；中途松手进度环倒退归零；走满后按钮左右轻震一下，变成对勾和「已删除」。适合删除等危险操作。

## 3. 可复用的提示词模板

视频真正的结论不是这 4 个特效，而是：**「好看」不可执行，参数才可执行。** 写动效需求时补齐这 6 个量，AI 出错的概率会掉一大截：

1. 触发条件（点击 / 按住 / 松手 / 滚动到某位置）；
2. 关键帧序列与百分比（先 0.8 → 1.2 → 1.0，而不是「弹一下」）；
3. 时长与缓动曲线名（600ms / ease-out-back / spring）；
4. 附属层（粒子数、涟漪、进度环、描边画勾、数字滚动）；
5. 中途打断的行为（松手倒退？重复点击排队还是忽略？）；
6. 结束态与回滚（恢复原状 / 停在成功态 / 落到新值）。

套成本项目的一句话模板：

> 给 `<组件>` 加 `<效果名>`：触发 `<事件>` 后 `<形变序列>`，时长 `<ms>`，缓动 `<曲线>`，同时 `<附属层>`；中途 `<打断行为>`；结束 `<回滚规则>`；`prefers-reduced-motion` 时 `<降级方案>`；只用 `transform/opacity`。

## 4. 发散：还值得考虑的特效

按「炫但有用」和「不炫但有用」混着排，每条给一句实现要点。

### A 按压与松手（手感的地基）

- **按压下沉 + 阴影收缩**：`active:` 时 `translateY(1px) scale(.98)` 且 box-shadow 变短，模拟真实行程。比单纯 `active:scale` 更像「按进去了」。
- **触点水波纹（Ripple）**：从指针/触摸坐标扩出一个半透明圆再淡出。MD3 语义，安卓用户预期强。CSS 变量 `--x/--y` + `::after` 即可。
- **磁吸按钮（Magnetic）**：光标进入 60px 半径时按钮朝光标偏移 8–12px，离开弹回。桌面端很抓眼，移动端无意义。
- **黏性按钮（Sticky）**：点击后不立刻回弹，指针离开才「啪」地弹回。适合主 CTA，做一次性惊喜。
- **长按呼出菜单**：与 04 的长按确认共用同一套指针计时器，一份代码两种语义。

### B 状态与形变

- **通用形变（morph）**：矩形 ↔ 圆形 ↔ 另一元素之间过渡。用 `border-radius` + `width/height` 过渡，或 FLIP + `clip-path`；View Transitions API 可跨元素。
- **滑动完成 / 滑动删除（slide-to-action）**：卡片横向拖出后露出底色与图标，松手过阈值执行、否则回弹。任务类 App 收益最高的一个手势。
- **骨架屏流光（shimmer）**：渐变带扫过占位块，比转圈更「快」的主观感受。
- **分段控件滑块挤压**：切换时滑块先拉长再复位（果冻开关的横向版），本项目 `Segmented.tsx` 已有滑块，只差挤压。
- **危险进度环**：04 的泛化——任何「不可撤销」动作都可以走按住蓄力，包括清空、覆盖恢复、删除文档。

### C 列表与布局

- **FLIP 重排补位**：删除/完成/换列后，其余卡片平滑滑到新位置，而不是瞬跳。`@dnd-kit` 的 `sortable` 自带，或用 Web Animations API 手写（先量旧位置 → 更新 → 反向 transform → 播放）。
- **级联错峰入场**：本项目 `.cascade` 已有（前 8 项各差 45ms），可推广到 ⌘K 结果、看板列、文档列表。
- **高度自适应展开**：`grid-template-rows: 0fr → 1fr` 或 `interpolate-size: allow-keywords`，替代写死 max-height 的假动画。
- **删除塌缩 + 兄弟补位**：卡片先横向轻微挤压再消失，配合 5.5 的撤销 toast。
- **下拉刷新橡皮筋**：跟手 + 阻尼 + 松手回弹，PWA 里最有「原生感」的一处。

### D 拖拽与手势

- **拖起态**：卡片抬起时 `scale(1.02)` + 阴影变大 + 极小随机旋转（±0.6°），落位时阴影收回。
- **落位回弹**：本项目 `DragOverlay dropAnimation={null}` 是硬贴回去，换成 dnd-kit 默认落位动画或自写 spring，成本极低。
- **投放区高亮**：`isOver` 时列容器底色 + 内描边呼吸，已有 `transition-colors`，可加轻微 `scale`。
- **抽屉跟手关闭**：`Sheet` 目前是固定 `slide-up`，加 `touchmove` 跟手 + 速度阈值判定，安卓返回键手感立刻不一样。

### E 数字与文本

- **滚动数字（odometer）**：每位数字竖排，`translateY` 滚动对齐；配合 `font-variant-numeric: tabular-nums` 防抖动。统计页三张 `StatCard` 直接可用。
- **数值变化高亮闪**：新旧值差时背景闪一次 300ms 渐变。
- **流式打字 + 光标**：AI 输出场景（当前 M3 已移除，恢复时可用）。
- **完成时文字划线动画**：`text-decoration` 换成伪元素 `scaleX(0→1)`，可控颜色与厚度。

### F 弹层与导航

- **共享元素转场**：列表卡片 → 详情页，用 View Transitions（Chrome 111+）做 `view-transition-name`，不支持时降级为淡入。
- **Toast 堆叠挤压**：新 toast 插入时把旧的往上顶，用 FLIP。
- **底部导航图标弹跳 + 指示胶囊**：`nav-pop` 已有，可加滑块在图标间移动。
- **主题切换圆形扩散**：从按钮位置用 `clip-path: circle()` 扩出整个新主题，比现在的全站 200ms 变色更有记忆点（View Transitions 一行搞定，不支持则保持现状）。

### G 氛围与质感

- **噪点/纸纹叠加**：`feTurbulence` 或 8px 平铺 PNG，透明度 2–3%，去掉「AI 生成的塑料感」。与本项目「暖纸中性」配色天然搭。
- **番茄钟呼吸光晕**：运行中让进度环外圈做 2–3s 极缓的 opacity 呼吸，静止时停掉。
- **完成撒花（confetti）**：Canvas 或 12 个 DOM 粒子，只在「今日全部完成」这类里程碑触发，日常任务不用。
- **进度环渐变描边**：`stroke` 用 `<linearGradient>`，专注时长接近完成时颜色往绿走。

### H 跨端反馈（本项目目前完全空白）

- **触觉 Haptics**：`@capacitor/haptics`（`selectionChanged` / `impactLight|Medium|Heavy` / `notificationSuccess|Warning|Error`），Web 端回退 `navigator.vibrate`（安卓 Chrome 可用，iOS 不可用）。这是「手感」最高性价比的一项——视频里 4 个特效在原生 App 上都该配一次轻震。
- **声音**：完成/删除各一个 40ms 短音，默认关，设置里开。谨慎做，容易变廉价。
- **减弱动效降级**：全局兜底已有（`index.css:81`、`:159`），新增特效必须走 `--dur-*` 令牌，粒子/canvas 类需在 reduce 时直接跳过而不是加速。

## 6. 红线（避免动效变噪音）

- 交互反馈 ≤400ms，页面级 ≤450ms；时长一律取 `--dur-1/2/3`，不写死 ms。
- 只给「有后果的操作」加特效（完成、删除、提交、切换、拖拽），纯浏览元素不加。
- 同一屏同时最多一个循环动画；番茄钟呼吸光晕在暂停时必须停。
- 只用 `transform` 与 `opacity` 做动画；粒子上限 12 个；不用 `box-shadow`/`filter: blur` 做逐帧过渡（安卓低端 WebView 会掉帧），阴影变化用切换类名 + 短时过渡。
- `color-mix()`、`linear()` 缓动、View Transitions 等按渐进增强写，minSdk 23 的老 WebView 要有可用降级。

**批 1（约半天，收益最高）**：`lib/haptics.ts` 基建 → 果冻开关 → StatsPage 数字滚动。三处互不影响，可分别验证。
**批 2（约 1 天）**：`Button` 扩 `state`（idle/loading/success/error）实现 Submit Morph，接到 5 个真异步入口 → Hold to Confirm 用于清空/恢复/删除文档，保留 Dialog 兜底。
