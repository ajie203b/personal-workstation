# 本地 Markdown 阅读

Windows 桌面版在「文档工作站」的文件夹图标进入本地阅读，也可在系统的「打开方式」中选择 Kairos 打开 `.md` / `.markdown` 文件。

- 左栏的「文件」显示同目录 Markdown 和子文件夹，「目录」显示当前文章的标题。侧栏可收起。
- 选择文件夹后，可在该文件夹及子目录内切换文件。跨出已打开目录的链接需要重新通过文件选择器打开。
- Markdown 相对链接和 PNG、JPEG、GIF、WebP、AVIF 本地图片按原文件的位置解析。标题锚点和数学公式可阅读。
- 外部编辑器保存后，阅读页会检查变更并刷新正文；返回窗口会刷新目录列表。列表也可手动刷新。
- 本地阅读直接读取原文件，不会把文件或目录结构导入文档库，也不参与坚果云同步。当前提供阅读，不回写原文件。
- 当前文本要求 UTF-8 编码，单篇上限 8 MB，本地图片上限 12 MB。

设置默认打开工具：安装含此功能的 Windows 安装包后，在一个 MD 文件上右键 → 打开方式 → 选择 Kairos，并勾选始终使用；也可从阅读设置进入系统默认应用设置，搜索 `.md` 或 `.markdown`。

文件关联由安装程序注册，开发网页无法测试 Windows 默认打开行为。实现使用 Tauri 的文件关联配置、系统文件选择器和单实例插件；已运行时双击另一个文件会交给现有窗口。
