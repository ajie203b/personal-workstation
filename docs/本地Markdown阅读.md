# 本地 Markdown 阅读与编辑

Windows 桌面版在「文档工作站」的文件夹图标进入本地阅读，也可在系统的「打开方式」中选择 Kairos 打开 `.md` / `.markdown` 文件。

- 从资源管理器打开的每个文件各占一个独立文档窗口，互不影响，也不会把主窗口切走或打断它正在进行的工作；再次打开同一文件会聚焦已有窗口。每个窗口只能访问自己打开的文件所在目录。
- 左栏的「文件」显示同目录 Markdown 和子文件夹，「目录」显示当前文章的标题。侧栏可收起。
- 选择文件夹后，可在该文件夹及子目录内切换文件。跨出已打开目录的链接需要重新通过文件选择器打开。
- Markdown 相对链接和 PNG、JPEG、GIF、WebP、AVIF 本地图片按原文件的位置解析。标题锚点和数学公式可阅读。
- 外部编辑器保存后，阅读页会检查变更并刷新正文；返回窗口会刷新目录列表。列表也可手动刷新。
- 打开文档后右上角只保留刷新和阅读设置；打开文件/文件夹入口只在未打开文档时显示。
- 右下角铅笔按钮进入编辑：直接改原文件的 Markdown 原文（无损，不做格式转换），停顿约 1 秒自动写回磁盘，Ctrl+S 立即保存，顶栏显示保存状态。编辑时暂停外部变更轮询；若保存发现文件已被其他程序修改，会暂停自动保存并让用户选择「重新加载外部版本」或「覆盖保存」。切换文件、返回前都会先落盘草稿；编辑中直接关窗（点 X / Alt+F4）也会先保存再退出，保存失败时窗口保留并提示处理。
- 首次高亮或转任务时，会创建关联的文档快照，复用文档库的批注、任务回链与同步能力。支持的本地 Markdown 图片会嵌入快照。
- 原文件变动后会更新已关联的快照并迁移批注关联。本地文件路径只留在本机，不进入同步。
- 阅读设置包含主题、字号、行距和正文宽度，按文档记忆。手动刷新会检查正文、图片和目录列表，并显示结果反馈。
- 当前文本要求 UTF-8 编码，单篇上限 8 MB，本地图片上限 12 MB。

设置默认打开工具：安装含此功能的 Windows 安装包后，在一个 MD 文件上右键 → 打开方式 → 选择 Kairos，并勾选始终使用；也可从侧栏底部的「默认应用设置」进入系统默认应用设置，搜索 `.md` 或 `.markdown`。

文件关联由安装程序注册，开发网页无法测试 Windows 默认打开行为。实现使用 Tauri 的文件关联配置、系统文件选择器和单实例插件；已运行时双击文件会经单实例转交给现有进程，为文件新开（或聚焦）独立文档窗口。
