# UI 体验核查与统一规范

核查日期：2026年10月22日。依据当前源码及隔离浏览器操作，涵盖 Muse 的两轮反馈。下面的「已修复」均包含实际修改；「未复现」不作为故障强行改动。

## 优先修复项

| 优先级 | 核查项 | 结果与处理 |
| --- | --- | --- |
| P1 | 自然语言时间只出现在 chips，表单为空 | 成立。开始/截止字段直接展示解析结果；手动覆盖或清空后不再被正文变化覆盖。重复任务同样保留手动截止时间优先。 |
| P1 | 未设开始时间却保存创建时刻 | 成立，表单和数据库原来都有默认值。两处均移除，创建时间与计划开始时间分开记录；已有任务不迁移。 |
| P1 | 划词没有高亮 | 部分成立。编辑器在桌面和手机上均能选词、高亮和保存；阅读器跨段选区会写入批注却不着色，已修复。Markdown、TXT 和 EPUB 支持跨段、反向、跨章节选区及刷新回放。 |
| P1 | 批注转任务后返回来源 | 追加复核发现 EPUB 使用了 Markdown 的 b 锚点，无法滚到来源。已统一 p/b/f 定位协议，任务保留完整摘录，返回章节后高亮进入视口并闪烁。 |
| P1 | 文档删除确认按钮为蓝色 | 成立。删除文档、文件夹以及删除/覆盖数据的确认统一使用危险色；恢复快照也按覆盖数据处理。 |
| P2 | 添加任务、快捷键弹窗没有 X | 成立。共用 Dialog 增加固定位置的关闭按钮；添加任务增加取消。保留遮罩、Esc 及键盘焦点管理。 |
| P2 | 日期格式散乱、详情显示秒 | 成立。集中使用日期工具：列表中文月日，详情/快照时间精确到分钟，日历使用中文年月日。输入值和存储用日期键，不拿它们充当展示文案。 |
| P2 | 强调色未覆盖番茄钟 | 部分成立，导航和普通按钮原本会随强调色变化，但番茄钟固定绿色。现专注主控件、时间与进度跟随强调色；今日 KPI 统一使用强调色，完成状态继续使用绿色。 |
| P2 | 完成后仍显示「今天没有安排」 | 成立。今日页和今日清单改为「今日暂无待办」。 |
| P2 | 今日空态与建议之间空白过大 | 成立。取消桌面紧凑空态的 32vh 最小高度，把今日建议放入任务所在列，避免被右侧番茄钟撑到底部。 |
| P2 | 优先级只有颜色、无含义说明 | 成立。任务列表显示「P0 紧急 / P1 重要 / P2 普通」和辅助色点。 |
| P2 | 英文榜单图片割裂 | 属于展示偏好。原图实际是随应用提供的资源，并非直接外链。按用户后续决定，保留 Artificial Analysis 官方原图，不重绘榜单；支持滑动、拖动、键盘滚动、查看完整原图及打开官网。原图加入 PWA 预缓存。 |
| P2 | 重置后蓝色描边残留 | 成立，来自共用卡片的 :focus-within。卡片描边现在只响应输入控件聚焦；按钮点击不再让整卡留下描边。键盘仍保留细焦点提示。 |
| P2 | 深色主按钮像禁用 | 视觉问题成立。主按钮使用更明确的强调色底与白字，12 种主题/强调色组合的主按钮文字对比度均达到 4.5:1；浅色的粉/橙/绿强调色也加深，兼顾小字可读性。 |
| P2 | 文档库空态说明难读 | 语义文字色本身没有复现低对比度，但小字号影响可读性；说明字号统一提升为 13px，保留有对比度的辅助文字色。 |
| P2 | 阅读/编辑窄侧栏出现半截文字 | 窄栏的文字原来靠透明度隐藏，存在过渡截断风险。现直接隐藏文字和计数，图标保留完整可访问名称与提示。 |
| P2 | 文档「继续阅读」与列表重复 | 成立。移除重复卡片行，主列表保留阅读进度、上次阅读日期和继续阅读操作。 |
| P2 | 番茄小说名称、清单术语、快捷键大小写 | 成立。入口及辅助名称统一「番茄小说」，清单统一「随时」，快捷键统一「N 或 /」。工具图标也不再使用危险色。 |
| P2 | 热力图省略星期、四象限火焰、周末红色 | 是设计选择，并非漏数据；本轮按反馈调整：补齐七天标签、立即做改普通行动图标、周末数字不再使用危险色。 |

## 未成立、未复现或属于历史范围的项目

| 项目 | 核查结论 |
| --- | --- |
| 添加任务、文档库、主题按钮混用 emoji | 提到的这些入口在本轮修改前已使用 Lucide SVG。保留该体系，另把今日回顾中的文本勾号换成同体系图标。 |
| 跳过新手引导会同时永久关闭首页卡片 | 未复现。两者使用独立的本机状态；桌面与手机均验证跳过后首页卡片仍在。卡片会因用户主动收起或已有最近阅读而隐藏。 |
| 深色模式吞掉番茄统计中的空格 | 未复现不同主题的文本差异。显示统一为显式模板字符串并避免换行。 |
| 桌面设置子导航与返回按钮重复 | 未复现。返回设置按钮只出现在手机二级设置页；桌面没有此按钮，不删手机必要的返回入口。 |
| AI 助手模块消失 | 属于历史产品范围。README 已记录旧 AI 资产入口下线、M3 助手面板未交付，本轮不恢复整套模块。历史产品方案补充明确说明，避免把规划当成现有功能。 |
| 全站 UTC 偏移、原生英文日期控件 | 按追加反馈撤回，不作为故障修改。另核对开始/截止字段：本地日期时间按本地解析，没有擅自转换成 UTC 截取日期。 |

## 后续界面规则

1. **图标**：操作图标使用 Lucide SVG；品牌和播放/暂停等媒体图标可保留专用 SVG。文字内的快捷键符号不作为装饰图标替代品。
2. **日期**：列表使用「10月22日」，跨年补年份；详情及快照使用「2026/10/22 15:25」；日历标题使用「2026年10月」。普通界面不显示秒。格式由 `src/lib/date.ts` 提供。
3. **弹窗**：普通弹窗共用 Dialog，标题区右侧提供「关闭」；录入提供取消与提交；危险确认使用 destructive 按钮，不能复用普通主操作颜色。
4. **颜色**：强调色用于导航、主操作、选中状态和专注控件；绿色用于完成/进行中，危险色用于删除、覆盖和错误。优先级附文字含义，不能只靠色点。
5. **文案和导航**：清单用「今日 / 近期 / 随时 / 将来」，工具用同一可见名称和可访问名称。窄侧栏仅显示图标；同一文档在库内只显示一张卡片。
6. **时间表单**：解析结果与字段展示一致，手动值优先，明确清空不能回退到旧解析值；未设开始时间保持未设置。
7. **高亮与来源**：新批注保存精确文本分片与偏移；旧批注优先匹配原正文。来源锚点由 `src/lib/docLocator.ts` 统一生成，避免跨阅读器混用。

## 验证

- 28 个测试文件、267 项测试通过，包含先复现失败再修复的任务表单、共用弹窗、跨段高亮、选区定位、批注转任务与快照字段用例。
- 生产构建通过，PWA 预缓存清单包含官方榜单原图。
- 官方原图支持本地缓存与离线刷新查看，榜单展示以用户选择的原图方案为准。
- 隔离浏览器检查 320、393、768、1024、1440px；核对深浅色、六种强调色、弹窗、日期、空态、导航、删除取消、榜单及无横向溢出。
- Markdown 正反向跨段、TXT 同章节跨段、EPUB 跨章节实际拖选，高亮刷新后保留；EPUB 转任务后能回到原文并闪烁，未发现页面运行异常。
- 测试使用独立浏览器资料和测试数据，没有操作用户已有任务、文档或同步账户。
