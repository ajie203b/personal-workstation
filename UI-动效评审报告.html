01 · 总评

一句话结论

视觉语言与 macOS「克制、材质分明、层次轻」的方向高度一致，动效已做到令牌化、只用 transform/opacity、并有 reduced-motion 兜底——工程素养高于多数同类个人项目。它现在的差距不再是「有没有动效」，而是「动效的物理精度与空间连续性」：缺共享元素转场、缺弹簧的真实阻尼手感、个别高频区域仍在逐帧改阴影/大面积模糊。

做得好的
  • 全站设计令牌化，零硬编码色值；深浅色双套完整
  • 动效时长/缓动统一走 --dur-* / --ease-*
  • 完成勾选 = 缩放 + 描边画勾 + 涟漪 + 6 粒爆点
  • 果冻开关、Segmented 挤压、长按蓄力环已落地
  • 主题切换用 View Transitions 从按钮位置圆形扩散
  • 跨端触觉反馈 + 全局减弱动效兜底
主要短板
  • 无共享元素转场：列表 → 详情是「开一个新面板」而非「同一元素长过去」
  • 弹簧用 cubic-bezier 近似，缺少真实阻尼/响应手感
  • 数字变化是瞬跳，缺 odometer 滚动 + tabular-nums
  • 玻璃模糊、阴影过渡存在掉帧隐患
  • 移动端缺滑动完成/删除这类高收益手势
  • 路由切换会重放整页级联入场，反复切换略显「晃」

03 · UI 视觉

暖纸中性 + 墨蓝主色，克制而有主张

没有落入「默认蓝模板」的俗套，配色定位清晰：--surface-2 #F7F6F3 的暖纸灰 + --primary #2C55B8 的墨蓝，整体质感偏「数字文具 / 编辑台」，与 macOS 的冷静中性色系不同，但同样克制。

亮点

  • 语义令牌完整（surface/outline/on-surface 三级），Tailwind v4 @theme inline 映射，主题切换零成本
  • 卡片 16px 圆角 + 1px 描边、刻意不加阴影，符合 HIG 的「平面 + 描边」克制感
  • 玻璃材质边界规则明确：只给顶栏 / 侧栏 / ⌘K 用
  • 弹层统一 20px 圆角 + 单层大柔和阴影（--shadow-pop）
  • 优先级四档色（红/橙/钢蓝/灰）与状态绿语义分离，避免配色打架
  • 文档阅读提供 日间/夜间/羊皮纸/暮色 四主题，编辑气质拉满

可改进

  • 卡片边界偏弱：暖纸灰 card 与白底对比度低，弱光屏上分区不清晰——可给 card 加 0.5–1% 的极浅投影，或用更细但更深的描边
  • 信息密度略高：侧栏图标行距、列表项节奏偏紧，与 macOS 侧栏更宽的呼吸感有差距
  • 原生控件一致性：主题开关（拟物）风格独树一帜，但和其余扁平控件不是同一套质感语言，属于「惊喜点」也属于「破谐」风险
  • 字体回退依赖系统 SF/PingFang，跨到非苹果设备（安卓/Windows）字形落差明显
结论：UI 是这份作品最强的部分。视觉主张明确、系统化程度高，唯一的「减法」建议是把 card 的分层做得再明确一档，让深浅两种环境下都有稳定的空间层次。
04 · 动效与流畅性

令牌化到位，缺的是「物理」

逐条核对了 index.css 与各组件，已落地的动效列表如下。整体判断：规范遵守得好，但缺少 macOS 那种「有质量、有阻尼」的连续感。

动效实现位置状态说明
完成勾选反馈CheckCircle已实现pop 缩放 + 描边画勾 + 绿色涟漪 + 6 粒爆点（对应方案 01）
果冻开关JellySwitch已实现translateX 位移 + knob-squash 挤压，运行时不改 left
分段控件挤压Segmented已实现滑块先拉长跨过中间距离再收回
长按确认蓄力环HoldToConfirm已实现rAF 计时、松手倒退、走满 nudge 轻震

流畅性亮点

  • 时长全部取 --dur-1/2/3，缓动取 --ease-standard/emph/spring，无散落魔法数字
  • 动画基本只用 transform / opacity，避开重排
  • reduced-motion 下粒子/涟漪/圆形扩散是直接隐藏而非「加速播完」——正确的无障碍做法
  • FLIP 用 WAAPI 且动画结束 cancel()，释放内联 transform，避免与按压态打架
  • 果冻开关用 transform 位移替代 left，避开逐帧重排

流畅性风险

  • 大面积玻璃模糊：.glass 用 backdrop-filter: blur(20px) saturate(1.6)，低端 Android WebView 上滚动/切页易掉帧
  • 逐帧改阴影：.press:active 与 .card-hover:hover 过渡 box-shadow，与方案「不用阴影做逐帧过渡」的红线相悖
  • 弹簧不真实：--ease-spring cubic-bezier(.34,1.36,.45,1) 是固定曲线，无法表达质量/阻尼，手感偏「数字」
  • 路由级联重放：.enter / .cascade 在每次页面挂载都重播，反复切页会持续「淡入晃」
  • 硬编码时长：Segmented 挤压用 setTimeout(…,150)，未走令牌
关键判断：当前动效「做对了方法，但差在物理」。macOS 的核心手感来自连续的弹簧积分与空间连续性——同一元素从来源位置长到目标位置。本站大量动效是「原地缩放 + 淡入」，因此单点精致、但整体仍偏「网页过渡」而非「原生运动」。
05 · 操作便捷性

效率工程扎实，键盘流是隐藏王牌

实测了完整操作链路：任务新增/完成/撤销、四视图切换、⌘K、主题、专注钟、文档导入。整体交互上手快、路径短，主要增益来自键盘与自然语言。

亮点

  • 全键盘工作流：⌘K 命令面板、? 快捷键、N 快速添加
  • 自然语言录入：输入「评审报告测试 明天14:00 P1 #工作」自动解析出时间/优先级/清单 chips，实时可视
  • 四视图（列表/看板/日历/四象限）共享同一数据，切换成本低
  • 危险操作走长按蓄力 + 键盘兜底弹窗，防误触且不牺牲无障碍
  • 完成→撤销 toast、触控热区 ≥40px、安卓返回键接管
  • 本地优先（IndexedDB + Dexie），无网络也能用，响应无延迟

可改进

  • 部分纯图标按钮（继续阅读/写作/删除）依赖悬停提示，触屏上不可发现
  • 缺移动端「滑动完成 / 滑动删除」——任务类 App 收益最高的手势
  • 空状态与「今天没有安排」引导较简短，可加更明确的下一步动作
  • 列表项拖拽与点击的分界（长按 200ms）在快速操作时偶有误触可能
  • 「继续写作」等动作按钮的视觉层级与主操作区分度可再明确

07 · 改进清单

按收益/成本排序的落地建议

每条都标明「做什么」「为什么」「怎么接」——引用实际文件与位置，便于直接实施。P0 = 半天内、收益最高；P1 = 1 天量级；P2 = 锦上添花。

P0 高性价比，优先做

① 统计卡数字滚动（odometer）

累计完成/连续打卡/专注时长等数值变化改为竖排数字滚动对齐，并给容器加 tabular-nums 防抖动。这是「一眼看到质感提升」的最低成本项。

落点：StatsPage.tsx 的 StatCard；注意：小数位需单独对齐，减弱动效时直接落值。

② 路由入场只播一次

把 .enter / .cascade 的播放限制为「会话内首次进入该视图」，避免反复切页持续淡入造成的「晃」感。

落点：各页面根容器；用会话级标记或路由级动画状态机控制在 AppShell。

③ 消除逐帧阴影过渡

.press:active 与 .card-hover:hover 改为切换类名 + 短过渡，或直接去掉阴影变化只保留位移。符合方案红线，也减少低端设备掉帧。

落点：index.css 的 .press / .card-hover。

④ 收敛玻璃模糊面积

为低端 Android WebView 提供降级：降低 backdrop-filter 的 blur 半径，或在设置里提供「性能优先」开关直接禁用玻璃。

落点：.glass；可加 @media (prefers-reduced-transparency) 或特性探测。

P1 手感升级

⑤ 引入真实弹簧

把固定 cubic-bezier 弹簧换成可调 damping/response 的弹簧（如 motion/Framer 的 spring 或 WAAPI 弹簧求解），让果冻开关、拖起落位、弹层出现具备「质量感」。

落点：统一到一套 spring 工具，替换 --ease-spring 使用处。

⑥ 共享元素转场

列表卡片 → 文档/任务详情用 view-transition-name 做空间连续，替代现在的「新开面板」。这是最接近 macOS 观感的一步。

落点：DocsPage/TaskItem → 详情；不支持时降级淡入。

⑦ 看板落位回弹

DragOverlay 拖完落位从硬贴改为带回弹的落位动画，列容器 isOver 时轻微 scale。

落点：BoardView.tsx；dnd-kit 默认落位动画或自写 spring。

⑧ 抽屉跟手覆盖全端

把 Sheet 的跟手下拉从「仅手机」扩展到桌面侧滑面板，并补齐骨架屏 shimmer 让等待更「快」。

落点：Sheet.tsx 的 isNarrow() 分支与列表加载态。

⑨ 移动端滑动完成 / 删除

任务卡片横向拖出露底色图标，过阈值执行、否则回弹。任务类 App 收益最高的手势，需与纵向滚动/点击/dnd 协调。

落点：TaskList 手机端；建议先只做「滑动完成」单一动作。

⑩ 统一硬编码时长

Segmented 挤压的 150ms 等散落数值收进 --dur-* 令牌，保证「系统减弱动效」时一并压平。

落点：Segmented.tsx。

P2 氛围与惊喜

⑪ 噪点/纸纹叠加

2–3% 透明度的平铺噪点，去掉「AI 塑料感」，与暖纸配色天然契合。

⑫ 番茄钟呼吸光晕

运行中进度环外圈做 2–3s 极缓 opacity 呼吸，暂停即停（同屏只保留一个循环动画）。

⑬ 进度环渐变描边

专注接近完成时描边色往绿走，用 <linearGradient> 描边。

⑭ 主题圆形扩散降级优化

非 View Transitions 环境保留全站 200ms 过渡即可，避免闪白。

⑮ 里程碑撒花

仅「今日全部完成」这类真实成就触发 12 粒 DOM 粒子，日常单任务不撒。

⑯ 卡片分层增强

给 card 加极浅投影或更深细描边，提升弱光环境下的空间层次。

08 · 红线与验证

别让动效变成噪音

必须守住的约束

  • 交互反馈 ≤400ms、页面级 ≤450ms；时长一律取 --dur-*
  • 只给「有后果的操作」加特效（完成/删除/提交/切换/拖拽），纯浏览元素不加
  • 同屏最多一个循环动画；番茄钟呼吸在暂停时必须停
  • 只用 transform / opacity；粒子上限 12；避免阴影/模糊逐帧过渡
  • 新增特效必须走 --dur-*，粒子类在 reduced-motion 下直接跳过
  • 危险操作不可牺牲键盘/Esc 路径

验收清单（每项改进自测）

  • 用 DevTools Performance 录制，确认无长任务、无强制重排
  • 开启「减弱动态效果」后，所有新动效降级正常、功能完整
  • 低端安卓真机（或 4× CPU 降速）验证滚动/切页帧率
  • 纯键盘走完全流程（Tab/Enter/Esc/⌘K）
  • 深/浅两套主题下动效均成立，无硬编码颜色
总建议：先做 P0 四项（半天内可完成），观感与性能会立刻改善；再用 P1 的「真实弹簧 + 共享元素转场」把整站运动质感从「网页级」提升到「接近原生」。这两步做完，本站在动效上就基本达到对标 macOS 的目标区间了。
